# RightKey to Obsidian Pro

一键将网页内容保存到 Obsidian 的 Chrome 扩展。让知识收集变得简单高效。

## ✨ 主要功能

- 🚀 快速保存：右键选中文本即可一键保存到 Obsidian，保留原文换行
- ⌨️ 快捷键：选中文本后按 `Alt+Shift+O` 直接保存（未选中时保存页面链接）
- 🔖 保存链接：在页面空白处右键，可"保存本页链接到 Obsidian"
- 📝 智能命名：使用选中文本前 20 个字 + 日期时间作为文件名，不会重名
- 🔗 笔记属性：自动写入标题、来源链接、保存时间和标签（frontmatter）
- 📁 灵活保存：可指定文件夹；可每次新建笔记，或全部追加到同一篇笔记
- 📏 长文本支持：内容过长时自动经剪贴板传递，避免保存失败
- ✅ 结果提示：保存后页面右上角和扩展图标都会显示结果
- 🎯 无干扰：可选择后台静默保存，不切换到 Obsidian

## 💡 使用场景

- 阅读文章时保存精彩段落
- 收藏网页上的重要信息
- 整理学习资料和笔记
- 收集写作素材和灵感

## 📦 安装步骤

1. 下载扩展文件并解压
2. 打开 Chrome 浏览器，访问：`chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择解压后的文件夹完成安装
6. 安装后会自动打开设置页面

## 🚀 使用指南

### 首次使用配置

1. 点击 Chrome 工具栏中的扩展图标
2. 点击"打开设置"按钮
3. 在设置页面输入您的 Obsidian vault 名称
   - 如果您的 Obsidian 路径是：`/Users/username/Documents/Obsidian/MyNotes` 或 `D:\Obsidian\MyNotes`
   - 则只需输入：`MyNotes`
4. 按需填写保存文件夹、保存方式、标签等选项
5. 点击"保存设置"，再点击"测试连接"确认能打开对应的 vault

### 日常使用

1. 在网页中选中想要保存的文本
2. 点击鼠标右键，选择"发送到 Obsidian"（或直接按 `Alt+Shift+O`）
3. 页面右上角提示"已发送到 Obsidian"，文本即保存到您的 Obsidian 笔记中

快捷键可在 `chrome://extensions/shortcuts` 中修改。

### 保存效果

新建模式下，保存的笔记示例（文件名：`桥梁定期检查报告 20261025-143005`）：

```markdown
---
title: "网页标题"
source: "https://example.com/article"
created: 2026-10-25T14:30
tags: ["web-clip"]
---

选中的文本内容

来源：[网页标题](<https://example.com/article>)
```

追加模式下，每条摘录会以 `## 2026-10-25 14:30` 为小节标题追加到同一篇笔记末尾。

## ⚠️ 注意事项

- 使用前请确保已安装 Obsidian 应用
- 首次使用时 Chrome 会询问是否打开 Obsidian，请勾选"始终允许"
- 支持 macOS 和 Windows
- 选中内容很长时会通过剪贴板传递，剪贴板原有内容会被覆盖
- Chrome 内置页面（如 `chrome://` 开头的页面）和 Chrome 网上应用店无法读取选中内容的换行，也不显示页面提示

## 🛠 故障排除

如果遇到问题，请检查：
| 现象 | 解决方法 |
|---|---|
| 点击后没有任何反应 | 检查是否已允许 Chrome 打开 Obsidian；在设置页点击"测试连接" |
| Obsidian 提示找不到 vault | vault 名称输入有误（区分大小写），在 Obsidian 左下角查看准确名称 |
| 右键菜单里没有"发送到 Obsidian" | 需要先选中文字；或在 `chrome://extensions/` 中重新加载扩展 |
| 保存的内容是剪贴板里的旧内容 | 网页阻止了剪贴板写入，可改为分段选择较短的文本 |
| 快捷键无效 | 在 `chrome://extensions/shortcuts` 检查是否与其他扩展冲突 |
